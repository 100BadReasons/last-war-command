# Last War Command

Recaps, goal progress and the game plan for my Last War account, built from screen recordings.

- `data/YYYY-MM-DD.json`: one snapshot per recording session
- `data/site.json`: goal, game plan and recaps
- `build_site.py`: builds `docs/index.html` (served by GitHub Pages)
- `build_sheet.py`: builds the Excel workbook used for analysis

```bash
python3 build_site.py
```
